# ✦ 모지픽 (MojiPick)

> 사진과 텍스트로 고민을 올리면 AI 캐릭터 **모지**가 분석하고 최선의 선택을 골라주는 풀스택 PWA 웹앱

---

## 1. 프로젝트 개요

**모지픽**은 사용자가 결정하기 힘든 상황(상품 비교, 선택지 고민 등)을 사진과 텍스트로 입력하면,  
AI 캐릭터 **모지**가 사용자의 프로필(이름·성별·나이·MBTI)과 **과거 결정 이력(별점·후기)**을 종합 분석하여  
최적의 선택지와 상세한 논리적 근거를 스트리밍으로 제시하는 풀스택 PWA 웹 애플리케이션입니다.

**최대 4명의 사용자 프로필**을 등록하고 전환할 수 있어, 가족이나 친구와 기기를 함께 써도 결정 기록이 섞이지 않습니다.

## 2. 타깃 페르소나 (Target Persona)

### 👤 핵심 사용자: "경제적 여유가 없는 학생"

| 항목 | 내용 |
|---|---|
| **연령** | 10대 후반 ~ 20대 초반 (고등학생, 대학교 1~2학년) |
| **경제 상황** | 용돈·아르바이트 수입에 의존, 구매 한 번 한 번이 부담 |
| **핵심 고민** | "이거 살까 저거 살까" — 잘못 고르면 환불도 못 하고 후회 |
| **결정 패턴** | 충동구매 후 후회 경험 多, 비교 분석에 시간과 에너지를 쏟기 싫음 |
| **기기 환경** | 스마트폰 중심 (모바일 퍼스트 UX 필수) |

### 🎯 페르소나가 겪는 문제 상황

```
"에어팟이랑 갤럭시 버즈 중에 뭐 살까... 둘 다 써보고 싶은데 하나만 살 수 있어."
"편의점 도시락 A랑 B 중에 뭐가 더 가성비야? 오늘 점심 예산 5,000원."
"이 강의 살까 말까... 학생 할인 끝나기 전에 결정해야 하는데."
```

### 💡 모지픽이 이 페르소나에게 제공하는 가치

- **가성비 분석 우선**: AI 프롬프트가 효율성·가성비·비용 대비 가치를 항상 핵심 비교 항목으로 다룸
- **과거 후회 학습**: 별점 1~2점을 남긴 결정 패턴을 기억해 "지난번에 비싼 거 사고 후회하셨잖아요" 식으로 잔소리
- **빠른 결정**: 복잡한 리서치 없이 사진 찍어 올리면 모지가 대신 분석 → 결정 피로 해소
- **무료 사용**: 광고·결제 없이 누구나 즉시 사용 가능
- **모바일 최적화**: 강의실·편의점 앞 등 어디서나 스마트폰으로 즉각 사용

## 3. 기술 스택

| 분류 | 사용 기술 |
|---|---|
| **Framework** | Next.js 15 (App Router) |
| **Language** | TypeScript (strict) |
| **Styling** | Tailwind CSS + Custom CSS Variables (다크/라이트 테마) |
| **Animation** | Framer Motion |
| **AI** | Google Gemini 2.5 Flash (`@google/generative-ai` SDK) — 멀티모달 |
| **PWA** | `manifest.json` + 모바일 설치 지원 |
| **State** | React Context API (`UserContext`, `ThemeContext`) |
| **Storage** | LocalStorage (다중 사용자 프로필, 결정 이력 15일 보존) |

## 4. 핵심 기능

### 랜딩 페이지 (`/`)
- 모지 캐릭터가 말풍선으로 서비스를 소개 (메시지 자동 순환)
- 프로필 등록 전: "지금 시작하기" → 온보딩으로 이동
- 프로필 등록 후: "모지에게 물어보기" + **"사용자 변경"** 버튼 노출
- 서비스 기능 카드 3개 (멀티모달 분석 / 실시간 스트리밍 / 15일 결정 기록)
- 결정 기록 바로가기 버튼

### 사용자 관리 (`/profiles`)
- **최대 4명** 사용자 프로필 등록 및 전환
- 프로필 카드 탭 → 해당 사용자로 전환 후 홈 복귀
- ✏️ 수정 버튼 → 해당 사용자 프로필 편집 (온보딩 수정 모드로 이동)
- ✕ 삭제 버튼 → 확인 모달 후 삭제
- 현재 활성 사용자에 "현재 사용자" 배지 표시
- 각 사용자의 **결정 기록이 완전히 분리**되어 관리

### 온보딩 (`/onboarding`) — 4단계
1. **이름 입력**
2. **성별 선택** (남성 / 여성 / 기타)
3. **MBTI 선택** (16가지 유형 + 모름)
4. **나이 입력**
- **신규 사용자 추가** (`?new=true`): 기존 프로필과 별개로 새 프로필 생성
- **기존 사용자 수정** (`?edit=true&profileId=xxx`): 특정 프로필만 수정
- 슬라이드 애니메이션으로 각 단계 전환

### 결정 입력 (`/decide`)
- **세부 상황** 텍스트 입력 (필수)
- **선택지 추가** — 이름(필수 1개 이상) + 이미지 업로드(선택사항, 탭하여 사진 선택)
- 선택지 무한 추가 / 삭제 가능
- 이미지 클라이언트 사이드 압축 (최대 600px, JPEG 변환) 후 Base64 전송
- 모지 캐릭터가 팁 말풍선 순환 노출 (사진 촬영 요령, 입력 방법 안내)
- 제출 전 유효성 검사 (상황 필수, 선택지 이름 1개 이상 필수)
- 제출 시 **현재 사용자의 최근 별점 이력 최대 5건**을 AI에 함께 전달 (취향 학습)

### AI 분석 결과 (`/result`)
- **로딩 → 스트리밍 → 완료** 3단계 상태 관리
- 로딩 중 모지 애니메이션 + 분석 진행 메시지 자동 순환
- 분석 완료 후 표시:
  - **비교 대상 태그** — 모지가 선택한 항목 강조 표시
  - **✦ 모지의 선택** 카드 — 최종 추천 선택지 대형 텍스트로 표시
  - **📋 모지의 분석 리포트** 카드 — 아래 7개 섹션으로 구성 (각 섹션 최대 6줄, bullet 요약체):
    - 🎯 이 선택을 한 이유 — 다른 후보 대비 우위 2개 이상 명시
    - ⚡ 효율성 분석 — 후보별 나란히 비교 형식
    - 💰 가성비 분석 — 비용 대비 가치 대조
    - ⭐ 실사용자 리뷰 & 반응 — 커뮤니티 반응 요약
    - ✅ 핵심 근거 — 사용자 프로필 반영 bullet
    - ⚠️ 이 선택의 단점 & 주의사항
    - 📊 선택지별 종합 비교 — 마지막 bullet에 한 줄 결론
  - 분석 불가 시 안내 메시지 표시

- **별점 & 후기 카드** (분석 완료 후 노출):
  - ⭐ 1~5점 별점 선택 (호버 시 확대 애니메이션)
  - 후기 메모 입력 (선택사항, 최대 200자)
  - 저장 시 히스토리 엔트리에 별점·메모 자동 업데이트
- 결정 기록 저장 시 **현재 활성 사용자 ID(profileId)** 자동 태깅

### 결정 기록 (`/history`)
- **현재 활성 사용자**의 최근 15일 결정 기록만 표시 (사용자별 완전 분리)
- 각 카드에 **모지의 선택 배지** 표시
- 별점 있으면 카드에 별 + 점수 + 후기 요약 표시
- 카드 펼치기 → 전체 분석 내용 + 만족도 섹션
  - 별점 없으면 "별점 남기기" 버튼
  - 별점 있으면 "수정하기" 버튼
- 헤더에 전체 평균 별점 자동 계산 표시
- 모지 말풍선 메시지가 평균 별점에 따라 변동
- **개별 삭제** (✕ 버튼 → 모달 확인) / **전체 삭제** (현재 사용자 기록만 삭제)

## 5. 다중 사용자 프로필 (Multi-Profile)

```
[사용자 변경 버튼] 또는 [지금 시작하기]
        ↓
[/profiles 페이지] — 최대 4명 목록
  ├── 카드 탭 → 해당 사용자로 전환
  ├── ✏️ 수정 → /onboarding?edit=true&profileId=xxx
  ├── ✕ 삭제 → 확인 후 제거
  └── + 사용자 추가 → /onboarding?new=true
        ↓
각 사용자별 결정 기록(/history)·취향 학습·AI 분석이 완전히 독립 관리
```

- 기존 단일 프로필 데이터는 앱 시작 시 자동 마이그레이션되어 정상 유지
- `localStorage`에 `decide_profiles` 배열 + `decide_active_profile_id`로 관리

## 6. AI 취향 학습 (핵심 차별점)

```
사용자가 별점을 남기면 → 다음 분석 시 Gemini에 과거 기록 전달
→ 모지가 패턴을 파악하고 자연스럽게 잔소리
```

- 별점 1~2점 결정과 비슷한 패턴 발견 시:
  > "지난번에 비싼 걸 샀다가 후회하셨잖아요. 이번엔 가성비를 조금 더 챙겨볼게요!"
- 별점 4~5점 결정의 공통점을 다음 추천에 반영
- 후기 메모 내용도 구체적으로 참고
- **사용자별 독립 학습** — 다른 사용자의 기록은 AI에 전달되지 않음

## 7. AI 분석 구조

- **모델**: `gemini-2.5-flash` (멀티모달, 최대 1M 토큰)
- **API 버전**: `v1beta` (systemInstruction 지원)
- **전달 데이터**:
  - 사용자 프로필 (이름, 성별, 나이, MBTI)
  - 선택지별 이름 + 이미지 (Base64 인라인)
  - 세부 상황 텍스트
  - 현재 사용자의 과거 결정 이력 (별점·후기 포함, 최대 5건)
- **응답 형식**: 마커(`★선택:`, `★분석불가`) 기반 구조화 스트리밍 텍스트
- **온도(temperature)**: 0.6

## 12. 데이터 흐름

```
[사용자 관리]
  /profiles에서 프로필 전환 (최대 4명)
  각 프로필 ID가 결정 기록·AI 학습 데이터에 자동 태깅
        ↓
[사용자 입력 — /decide]
  이름/성별/나이/MBTI (UserContext, LocalStorage 저장)
  선택지 이름 + 이미지 → 클라이언트 압축 → Base64
  세부 상황 텍스트
  현재 사용자의 과거 결정 이력 (별점 있는 것만, 최대 5건)
        ↓
[/api/analyze Route Handler]
  Gemini 2.5 Flash API 호출 (systemInstruction + 멀티파트)

        ↓
[/result 페이지]
  마커 파싱 → 모지의 선택 + 분석 리포트 표시

        ↓
[/history 페이지]
  현재 활성 사용자(profileId) 기준으로 15일 이내 기록 필터링
  별점/후기 표시 및 수정
  평균 별점 계산 표시
  개별/전체 삭제 (현재 사용자 기록만 영향)
```
